# Nuestro pequeño universo ✨

Página web romántica de cumpleaños hecha con HTML, CSS y JavaScript puro. No requiere frameworks ni instalación.

## Cómo abrirla
1. Descomprime la carpeta.
2. Abre `index.html` en tu navegador (Chrome, Firefox, Edge, etc.).
3. Para editar el proyecto, abre la carpeta con Visual Studio Code.

## Personalización rápida
### 1. Cambiar el nombre
Abre `script.js` y modifica:
```js
const CONFIG = {
  nombre: "mi persona favorita"
};
```
Por ejemplo: `nombre: "Sara"`.

### 2. Añadir fotografías
Copia tres imágenes a la carpeta `fotos` y ponles estos nombres exactos:
- `foto1.jpg`
- `foto2.jpg`
- `foto3.jpg`

Si son `.png` o `.webp`, cambia también el nombre de archivo correspondiente en `index.html`.

### 3. Añadir música
Pon un archivo de audio que tengas derecho a usar en la carpeta `musica` y nómbralo `cancion.mp3`. La música se activa al pulsar el botón; no empieza automáticamente porque los navegadores suelen bloquear la reproducción automática.

### 4. Personalizar la carta
Abre `index.html` y busca el bloque `id="carta"`. Cambia los párrafos de ejemplo por tus propias palabras.

### 5. Cambiar mensajes
En `index.html`, puedes editar los títulos, las descripciones de los recuerdos, el mensaje de las velas y el mensaje secreto.

## Tecnologías
- HTML: contenido y estructura.
- CSS: galaxia, diseño adaptable, torta y animaciones.
- JavaScript: estrellas en Canvas, música, navegación, velas, confeti y mensaje secreto.

## Nota
La tipografía de Google Fonts requiere conexión a Internet. Si no hay conexión, la página usa tipografías de respaldo. Todo lo demás funciona localmente.
